# Stellar Burgers

Одностраничное приложение (SPA) для сборки и заказа «космических» бургеров.  
Проект разработан в рамках обучения на курсе «React-разработчик» от Яндекс.Практикум, но доведён до уровня полноценного портфолио-приложения с тестами, оптимизацией и деплоем.

**Демо:** https://nsurcukov.github.io/stellar-burgers/

## Функциональность

- **Сборка бургера** с drag-and-drop (перетаскивание ингредиентов в конструктор)
- **Регистрация, авторизация, восстановление пароля**
- Защищённые маршруты (доступ к профилю и истории заказов только после логина)
- **Личный кабинет** с редактированием профиля и выходом из аккаунта
- **Лента заказов** (общая и личная) с подключением по WebSocket для обновлений в реальном времени
- Модальные окна с деталями ингредиентов и заказа
- Адаптивная вёрстка (desktop, tablet, mobile)
- Обработка ошибок API и обновление токенов

## Технологический стек

- **React** (functional components + hooks)
- **TypeScript**
- **Redux Toolkit** + **Redux Thunk** (управление состоянием и асинхронные действия)
- **React Router Dom** (роутинг и защищённые маршруты)
- **React DnD** (drag-and-drop в конструкторе)
- **WebSocket** (реальное время в ленте заказов)
- **Webpack** (сборка проекта, code splitting, оптимизация)
- **CSS Modules** (модульные стили)
- **REST API** (взаимодействие с сервером Яндекс.Практикум)
- **Jest** + **React Testing Library** (unit- и интеграционные тесты)

## Тестирование

Проект покрыт тестами:

- Unit-тесты редьюсеров и действий (ingredients, constructor, order, user и др.)
- Интеграционные тесты ключевых компонентов:
  - BurgerConstructor (сборка, drag-and-drop, расчёт цены)
  - BurgerIngredients (табы, скролл к секциям)
  - Modal и модальные окна
  - ProtectedRoute (редиректы при отсутствии авторизации)
  - Формы авторизации и регистрации

## Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/nsurcukov/stellar-burgers.git

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start
# Приложение будет доступно на http://localhost:3000

# Сборка продакшн-версии
npm run build

# Запуск тестов
npm test

# Деплой на GitHub Pages
npm run deploy
